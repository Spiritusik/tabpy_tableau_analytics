# TabPy MGRS Converter

Небольшой проект для использования Python-функций в Tableau через TabPy.  
Пример: конвертация MGRS координат в latitude/longitude.

## Структура проекта

```text
tabpy-project/
├── app/
│   ├── __init__.py
│   └── geo/
│       ├── __init__.py
│       └── mgrs.py
├── deploy.py
├── requirements.txt
└── README.md
```
